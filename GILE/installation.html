Installation

Requirements and step-by-step instructions for installing GILE on Fabric.

1. Minimum Requirements

GILE strictly requires the Fabric Loader and the Fabric API. Please ensure you are matching your mod version with the exact dependencies listed below.

GILE Version Minecraft Version Fabric Loader Fabric API Java Version
1.0.0 Release ~26.1 >= 0.19.3 0.145.1+26.1 Java 25+
0.1.5 Beta ~1.21.1 >= 0.19.2 0.116.11+1.21.1 Java 21+
Warning: GILE will not function without the correct version of the Fabric API present in your mods folder!
  1. Install Fabric: Download and run the Fabric Installer for your targeted Minecraft version.
  2. Download Fabric API: Download the matching version of Fabric API .
  3. Download GILE: Download the .jar file for Genshin Impact: Lunar Expansion from CurseForge or Modrinth .

3. Open Your Minecraft Mods Folder

Once Fabric is installed, you need to place the GILE .jar and the matching Fabric API .jar inside your Minecraft mods folder.

The location of this folder depends on your operating system. Here are the default Minecraft paths:

🪟 Windows

Press Win + R, paste the path below, and press Enter.

%APPDATA%\.minecraft\mods
This opens the Minecraft mods folder directly.
🍎 macOS

In Finder, choose Go → Go to Folder... and enter the path below.

~/Library/Application Support/minecraft/mods
You can also press ⌘ Command + Shift + G in Finder.
🐧 Linux

Open your file manager and navigate to your Minecraft directory using the path below.

~/.minecraft/mods
The .minecraft directory may be hidden. Enable hidden files if necessary.
💡 Don't have a mods folder?
If the folder does not exist yet, simply create a new folder named mods inside your Minecraft directory.

4. Put the Mods Inside

Your mods folder should contain at least these two files:

📁 .minecraft
  └── mods
      ├── Fabric API .jar
      └── GILE .jar

Do not extract the .jar files. Place the downloaded files directly into the mods folder.

5. Launch GILE

  1. Open the Minecraft Launcher.
  2. Select the Fabric installation for the Minecraft version you installed GILE for.
  3. Click Play.
  4. Once Minecraft starts, GILE should load automatically alongside Fabric API.
⚠ Version matters.
Make sure the GILE version, Minecraft version, Fabric Loader version and Fabric API version are compatible with each other. If Minecraft crashes during startup, check the Known Issues page first.
